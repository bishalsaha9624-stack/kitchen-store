# Kitchen Store

School kitchen stock app: stock in/out, daily meals, monthly registers (PDF/Excel). No sign-in: anyone with the link can use it; data syncs live through Firebase.

- **Web app:** https://bishalsaha9624-stack.github.io/kitchen-store/ (files in `docs/`)
- **Android app:** [KitchenStore.apk](https://github.com/bishalsaha9624-stack/kitchen-store/releases/download/latest/KitchenStore.apk) – opens the web app.
- **Data:** Google Firebase Firestore. Settings in `docs/config.js`, security rules in `firestore.rules` (open access).
